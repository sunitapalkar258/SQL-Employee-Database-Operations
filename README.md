# SQL Employee Database Operations

This project contains SQL queries and database operations performed on an Employee dataset using SQL Server.

## 📌 Project Overview

The project focuses on creating and managing an Employee database and performing different SQL operations such as data insertion, updating records, deleting records, filtering data, and performing aggregate analysis.

The Employee dataset contains information such as employee ID, employee name, department, salary, experience, city, project name, and project status.

## 🗂️ Dataset

The dataset contains 12 employee records from the following departments:

* IT
* HR
* Finance

The dataset also includes employee salary, experience, city, project name, and project status.

## 🛠️ SQL Operations Covered

* CREATE TABLE
* INSERT INTO
* UPDATE
* DELETE
* WHERE
* GROUP BY
* COUNT()
* SUM()
* AVG()
* ORDER BY
* TOP
* Filtering using multiple conditions
